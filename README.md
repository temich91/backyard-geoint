# backyard-geoint
Проект в рамках курса "Распознавание образов"

**Задача**: поиск локации по фотографии в пределах одного города (Visual Place Recognition).

**Входные данные**: панорамы улиц из Mapillary с метками геолокации

## Пайплайн

1) **Сбор и предобработка датасета**
   * Загрузка панорам с определенным шагом между точками съемки
   * Разбиение панорам на несколько кадров (с заданным полем зрения)
   * Разрешение дубликатов, создание собственных ID (если надо)
   * Пространственный сплит (Spatial Split) на train/val/test без географического перекрытия (во избежание утечки данных)
   * Создание класса датасета для последующей работы в PyTorch

2) **Создание модели для распознавания локации**
   * Реализация архитектуры MixVPR на основе ResNet50 на PyTorch
   * Извлечение эмбеддингов для тренировочных данных

3) **Реализация векторного поиска в FAISS**
   * Построение индекса по эмбеддингам
   * Привязка метаданных: сопоставление внутренних ID векторов в индексе с метаинформацией (GPS-координаты `lat`, `lon`, ID кадра)
   * Консольный интерфейс для запросов: прием тестового изображения, поиск топ-$k$ ближайших кандидатов, вывод предсказанных координат и расстояний

4) **Тестирование качества поиска и критерии успеха**
   * **Критерий истинности (Ground Truth)**: предсказание считается верным, если найденный кандидат находится в пределах радиуса $r \le 50$ метров от истинной точки съемки
   * **Ключевые метрики**:
     * `Recall@k` ($k \in \{1, 5, 10\}$) — доля запросов, для которых хотя бы один из топ-$k$ кандидатов попал в радиус $r$
     * Средняя и медианная ошибка локализации (расстояние в метрах между истинной точкой и ближайшим предсказанным кандидатом)
   * Итоговая проверка качества на отложенной тестовой выборке

## Структура проекта

```text
├── data/
│   ├── raw/                 # Исходные панорамы и метаданные Mapillary
│   ├── processed/           # Нарезанные перспективные изображения
│   └── splits/              # Файлы разметки и гео-сплитов (train/val/test)
├── configs/                 # Конфигурационные файлы (параметры модели, обучения, путей)
├── src/
│   ├── data/                # Загрузка Mapillary, нарезка панорам, гео-сплит, PyTorch Dataset
│   ├── models/              # Архитектура MixVPR (бэкбон + Feature Mixer)
│   ├── training/            # Trainer, функции потерь, сэмплирование пар/триплетов (hard-negative mining)
│   ├── search/              # Построение и сериализация индекса FAISS, модуль векторного поиска
│   ├── utils/               # Вспомогательные скрипты
│   └── eval/                # Расчет Recall@k, метрик расстояния и валидация
├── scripts/                 # CLI-скрипты запуска этапов пайплайна (сбор, индексация, поиск, оценка)
├── pyproject.toml           # Зависимости проекта (PEP 621) и конфигурация инструментов
├── README.md
└── .gitignore               # Для крупных файлов данных, чекпоинтов моделей и faiss-индексов
```

## Рабочий процесс
* **`main`** — релизная стабильная версия
* **`dev`** — основная ветка для интеграции отдельных задач
* **`feature/<name>`** — ветки для отдельных задач (ответвляются от `dev`)
* **`fix/<issue>`** — исправление ошибок

Файлы данных (data/raw/, data/processed/), обученные веса (\*.pth, \*.pt) и файлы индексов (\*.faiss)
не коммитятся в Git и обязательно добавляются в .gitignore.

Кросс-ревью: по готовности задачи открывается pull request в ветку dev.

## Установка и развертывание

Для быстрого и воспроизводимого управления зависимостями в проекте используется [**uv**](https://github.com/astral-sh/uv).

### Требования
* Установленный **uv** (или стандартный `pip`)

---

### Быстрый старт с `uv`

1. **Клонирование репозитория:**
   ```bash
   git clone https://github.com/temich91/backyard-geoint.git
   cd backyard-geoint
   ```
   
2. **Создание виртуального окружения:**
   ```bash
   uv venv --python 3.12
   ```

3. **Активация окружения:**
   * **Windows (PowerShell):**
     ```powershell
     .venv\Scripts\Activate.ps1
     ```
   * **Linux / macOS:**
     ```bash
     source .venv/bin/activate
     ```

4. **Установка проекта и зависимостей:**
   ```bash
   uv pip install -e .
   ```

**Поддержка GPU (CUDA):**
По умолчанию устанавливается базовая версия для CPU. Для ускорения на видеокартах NVIDIA установите PyTorch с поддержкой CUDA:
```bash
uv pip install torch torchvision --index-url https://download.pytorch.org/whl/cu121
```

---

### Альтернатива: Стандартный `pip`
```bash
python3.12 -m venv .venv
# Активация (.venv\Scripts\Activate.ps1 на Windows или source .venv/bin/activate на Linux)
```
